# Infomaniak Core - Multiplatform

Kotlin Multiplatform libraries and Gradle plugins shared by Infomaniak apps.

- [`features/`](features): feature modules, e.g. [`Sample`](features/Sample).
- [`plugins/`](plugins): published Gradle plugins.
- [`build-logic/`](build-logic): internal convention plugins of this repository.

Each module is versioned and released independently, see [Publishing](docs/PUBLISHING.md).
