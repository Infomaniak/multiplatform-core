# Sample

Template feature module. It targets **Android** and **JavaScript** (browser and Node.js), so its API can be consumed
from Kotlin Multiplatform projects and from JavaScript/TypeScript projects.

## JavaScript / TypeScript

The `js` target is configured as a library (`binaries.library()`) using ES modules, with TypeScript definitions
generated by the compiler. Only declarations annotated with `@JsExport` are exposed to JavaScript.

The business logic lives in `commonMain`, in plain Kotlin, and is compiled for every target:

```kotlin
// commonMain
fun sampleMessage(): String = "Hello from Sample feature"
```

`commonMain` stays free of JS-specific annotations: the JavaScript/TypeScript API is a facade in `jsMain`
(package `com.infomaniak.multiplatform_core.feature.sample.js`) that exports and delegates to the common code:

```kotlin
// jsMain
@JsExport
fun sampleJsMessage(): String = sampleMessage()
```

The facade is also the place to adapt types that cannot be exported as-is (e.g. `suspend` functions exposed as `Promise`)
and to choose what is part of the public TypeScript API.

### Alternative: `@JsExport` in `commonMain`

`@JsExport` can also be used directly in `commonMain` (it is ignored on non-JS targets). It is shorter, but it mixes JS
concerns into the common code and exposes the common API as-is, so prefer the facade.

Build the npm package:

```bash
./gradlew :features:Sample:jsBrowserProductionLibraryDistribution
```

The package (`package.json`, `.mjs` and `.d.mts` files) is generated in `features/Sample/build/dist/js/productionLibrary/`,
and can be used from TypeScript:

```ts
import { sampleJsMessage } from "@infomaniak/multiplatform-core-sample";

const message: string = sampleJsMessage();
```

To try it locally in another project: `npm install <path-to>/features/Sample/build/dist/js/productionLibrary`.

## Publishing

The module is released independently (Gradle artifact `com.infomaniak.multiplatform_core:sample`, tag
`sample-<version>`), see [Publishing](../../docs/PUBLISHING.md). Its npm package `@infomaniak/multiplatform-core-sample`
is not published yet (`"publish-npm": false`).

## Tests

`commonTest` runs on every target:

```bash
./gradlew :features:Sample:allTests
```

`jsBrowserTest` runs the tests in Chrome headless (Karma), so Chrome must be installed. `jsNodeTest` runs them with
Node.js, downloaded by the Kotlin Gradle plugin.

## Yarn lock file

The Kotlin/JS tooling resolves npm dependencies with Yarn and stores the lock file in `kotlin-js-store/yarn.lock`
(committed). If the JS dependencies change, update it with:

```bash
./gradlew kotlinUpgradeYarnLock
```
